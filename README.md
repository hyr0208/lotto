# ☕ 커피 찾기

지뢰찾기에서 영감을 받은 팀 내기 게임입니다.
뒤집어진 칸 중 어딘가에 커피가 숨어 있습니다. 걸리면 당신이 쏩니다.

## 게임 방법

1. 참가자 이름을 순서대로 입력합니다
2. 칸 수와 숨길 커피 개수를 설정합니다
3. 순서대로 돌아가며 `?` 칸을 하나씩 선택합니다
4. `✓` 가 나오면 안전, `☕` 가 나오면 그 사람이 커피를 삽니다

## 주요 기능

- 참가자 추가 / 삭제, 순서 표시
- 칸 수 선택 (9 / 12 / 16 / 20칸)
- 커피 수 설정 (1 ~ 3개)
- 같은 멤버로 바로 재시작 가능

## 기술 스택

| 항목       | 내용            |
| ---------- | --------------- |
| 프레임워크 | React 18        |
| 언어       | TypeScript      |
| 스타일링   | Tailwind CSS v3 |
| 빌드 도구  | Vite 5          |

## 시작하기

```bash
npm install
npm run dev
```

> **Node.js 버전 참고**
> Vite 6은 Node.js 20.19+ / 22.12+ 를 요구합니다.
> Node v20.11 이하 환경에서는 이 프로젝트처럼 Vite 5를 사용하세요.

## 빌드

```bash
npm run build
```
