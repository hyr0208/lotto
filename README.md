# 🎲 제비뽑기

공정한 랜덤 추첨 웹 서비스입니다. 커피 내기, 발표 순서 정하기, 당번 뽑기 등 다양한 상황에서 활용할 수 있습니다.

## 기능

- 참가자 추가 / 삭제 / 일괄 입력
- 당첨 인원 수 설정 (복수 당첨 지원)
- 뽑기 애니메이션 (카운트다운 → 이름 룰렛 → 결과)
- 다시 뽑기 / 처음으로 초기화

## 기술 스택

- React 18
- TypeScript
- Tailwind CSS v3
- Vite 5

## 개발 환경

Node.js 20.19+ 또는 22.12+ 권장
(Node v20.11 환경에서는 Vite 5를 사용)

## 시작하기

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
